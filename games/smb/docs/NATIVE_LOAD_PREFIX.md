# Native load-prefix snapshots

A native area-load epoch can end before gameplay starts. In the frozen 336 mood corpus, 1-3 epoch 7 of input 6a33d619 ends inside ScreenRoutines: mode1/task1/engine0 on all 157 retained rows. Searching for engine7/8 cannot initialize that epoch and must not pretend the omitted screen controls were compared.

`decodeNativeLoad` accepts only mode1/task1 or2, or task3/engine0. The caller must supply a unique static ROM area binding. Its fields come from OperMode_Task$0772, GameEngineSubroutine$0e, ScreenRoutineTask$073c, DisableScreenFlag$0774, ScreenTimer$07a0, ColumnSets$071e, GameTimerExpiredFlag$0759 and the source DisplayIntermediate branch. That branch skips lives display when AltEntranceControl$0752 is nonzero, or when AreaType$074e is not castle and DisableIntermediate$0769 is nonzero. No elapsed-row constant determines the transition.

One initial RAM snapshot seeds the existing NativeLevelLoad runtime. It does not seed the swimming gameplay motor from pre-gameplay aliases. The comparison steps each following native input through the last loader-only row, before the first source engine7/8 row. It compares source task/engine/screen/disable/timer/columns, FrameCounter, the full random register, shared interval phase, Mario/camera, HUD and supported actors. A changed final ColumnSets byte fails the regression. Ambiguous ROM bindings are not aligned by Mario position.

`native-mood-load-prefix.ts --cache CACHE --out REPORT` audits these prefixes without changing the cache. `--hashes SHA --fixture FILE` retains portable raw RAM/input cases. The normal mood audit stores each result as controlPrefix and counts its stepped/aligned rows separately from the independently initialized gameplay replay. The seed row itself remains outside predicted coverage; boot, title, game-over, later unsupported states and pixel parity are still explicit outstanding coverage.

The immutable all 336 survey on runtime 0b3ce5b initializes all 2,681 load prefixes and compares 330,562 PPU rows with zero control/pose/HUD differences. 1,850 prefixes pass the supported strict actor audit; 477 retain unsupported-family diagnostics and 354 expose missing terrain-born Piranhas/pole flags. Those are failures to fix, not successful matches. The load-only 1-3 epoch contributes 156 independently predicted rows. `native-load-prefix-audit.json` records each prefix's source input/RAM hashes and the full report/tool hashes. This is snapshot-scoped control evidence, not a claim of uninterrupted POWER-ON or pixel equivalence.

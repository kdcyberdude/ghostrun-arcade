# Spring slot and anchor strict readout

Native terrain `Jumpspring` creates ID50 in the first free enemy slot, falling back to slot5. It stores the same source Y in Enemy_Y_Position and Jumpspring_FixedYPos ($58+slot), sets YHigh to1 and increments the slot flag. It does not call InitEnemyObject: Enemy_State is retained and is not a spring control byte.

`JumpspringHandler` sets raw Y to FixedY plus `[8,16,8,0][JumpspringAnimCtrl-1]` while compressed. The existing source motor retains the compression drawn in that pass, even if the handler increments its control afterward. Strict simulation readout uses the actual springSlots registry and `springCompression`, with raw anchor `spring.y - 24 + compression * 8`. It does not infer an active spring from a declaration or silently substitute idle when compression ownership is absent. Native parser identity and the slot/compression adapter are required for complete model coverage.

`native-strict-springs.ts` retains all 3,777 ID50 lifetime rows from six original inputs: 3,766 live rows and 11 erasure rows. The fixture includes original input/RAM hashes, raw X/Y/page, retained state and fixed Y. Tests cover all three drawn offsets, source motor transitions, slot5, mismatched positions/slots/lifetimes, and missing ownership. Enemy_State is deliberately not invented in the simulation readout; its retained value is recorded in the fixture. This unit adds actor comparison coverage and does not claim pixel parity or repair earlier runtime divergences.

The flag-phase actor pass now applies the same source OffscreenBoundsCheck to springs in ascending enemy-slot order. An occupied spring slot runs its handler and is not reconsidered for frenzy spawning on its erasure row; later slots can observe the freed bank entry. Continuous 2-1 replay from the original authenticated entrance checks every spring anchor/lifetime through 2,789 retained same-level frames, including erasure at native frame 2,203 after camera reaches 3,081. No room or flag reseeding is used. Broader earlier gameplay failures remain separate and visible.
